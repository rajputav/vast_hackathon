# vast_hackathon

Initial setup.

## Deploy

From the workshop VM:

```bash
./deploy.sh
```

Then open https://workshop.thecosmoslabs.com and click **App**. The page shows whether VSS, Cosmos and W&B are reachable; search for something, play a clip, and click **Ask Cosmos** to test the full path.

Re-run `./deploy.sh` after any change in `app/`.
